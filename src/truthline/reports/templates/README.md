# Report templates

Agency-specific drafts render from the case-file data. Planned for v0.1:

| Template | Destination | Notes |
| --- | --- | --- |
| `fbi_tip.md` | tips.fbi.gov / field office | Threats; include original, sender handle, date/time |
| `ic3.md` | ic3.gov | Fraud, extortion, impersonation |
| `ncmec_cybertip.md` | report.cybertip.org | Any case involving a minor; file is never attached, hash only |
| `safe2tell.md` | Safe2Tell / Say Something | School threats; attaches the case file |
| `ftc_reportfraud.md` | reportfraud.ftc.gov | Scams, fake reviews, impersonation |
| `preservation_request_2703f.md` | For a police officer to send to a platform | Only a governmental entity may send it; the tool drafts it |

Templates are offered under Apache-2.0 so agencies and vendors can reuse them.
